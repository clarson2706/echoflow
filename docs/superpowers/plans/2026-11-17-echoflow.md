# EchoFlow Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** A Windows voice app: hold Ctrl+Space to dictate cleaned text into any app, a note mode that ends in a structured note, and a searchable history dashboard.

**Architecture:** An Electron shell (tray, global hotkey, overlay pill, audio capture for mic and system loopback, paste) talks over localhost HTTP to a Python engine (faster-whisper adapted from Murmur, cleanup providers, fact verifier, SQLite + FTS5). The dashboard UI is static HTML served by the engine.

**Tech Stack:** Electron, uiohook-napi, Python 3.12 (uv), faster-whisper, FastAPI/uvicorn, SQLite FTS5, pytest, Playwright (UI/e2e tests).

**Spec:** `docs/superpowers/specs/2026-11-17-echoflow-design.md`

## Global Constraints

- Windows 11 first; reference GPU RTX 3060 Ti 8 GB. MIT license. English only.
- Transcription always local. Cloud only if the user supplies a key. No telemetry.
- Cleanup must never lose a number, date or capitalized name; on verifier failure insert the rule-based text.
- Dictation target ~1 s after release (rule-based/cloud); local LLM may take 2-3 s.
- Hold-to-talk default Ctrl+Space; note toggle Ctrl+Shift+Space; both configurable.
- Paste via clipboard with restore; on failure copy text and toast. Window titles never leave the machine.
- Keys never stored in the database or repo.
- Design: whites and creams, old money, liquid glass (glassmorphism).

## Review Focus

1. Silent or very short capture -> nothing inserted, no LLM call.
2. Provider down/timeout -> rule-based text inserted, entry flagged `fallback`.
3. LLM drops a number or name -> verifier rejects, rule-based text used.
4. Clipboard contents before dictation are restored afterwards.
5. Engine dies -> shell restarts it; note-mode transcript survives a restart.

## Tasks

### Task 1: Engine core (hardware, transcription, db)
**Files:** `engine/pyproject.toml`, `engine/src/echoflow_engine/{hardware,transcribe,db}.py`, `engine/tests/test_db.py`
**Produces:** `hardware.detect() -> dict`, `transcribe.Transcriber(model, device).run(pcm: np.ndarray) -> (text, segments)`, `db.Store(path)` with `add_entry/search/get/update/delete/settings/dictionary`.
- [ ] Test: Store adds entries, FTS search finds by word in raw or cleaned text, delete removes, settings round-trip, dictionary round-trip.
- [ ] Implement Murmur-derived hardware + model loading (CUDA lib registration, int8_float16, CPU fallback) and the SQLite store.

### Task 2: Cleanup and fact verifier
**Files:** `cleanup.py`, `verify.py`, `providers.py`, tests for each.
**Produces:** `cleanup.rule_clean(raw, style, dictionary) -> str`; `verify.facts_preserved(raw, cleaned) -> bool`; `providers.get_provider(settings).clean(raw, style, dictionary, app) -> str | None` (Gemini, OpenAI-compatible; None = unavailable); `cleanup.clean(raw, style, dictionary, app, settings) -> (text, provider_used, fallback_flag)`.
- [ ] Tests: filler removal, self-correction ("Tuesday, no, Wednesday"), spoken commands, dictionary, styles (bullets, todo, email, message), verifier accepts reworded text and rejects a dropped number/name, provider failure falls back, verifier failure falls back (mock provider).

### Task 3: Notes
**Files:** `notes.py`, `tests/test_notes.py`
**Produces:** `notes.NoteSession` (append PCM, cut at quiet point every ~15 s, transcribe, live transcript), `notes.build_note(transcript, template, settings) -> markdown` (LLM if configured, rule-based otherwise), session recovery file.
- [ ] Tests: rule-based note has title, summary, sections, action items; session cut never splits mid-buffer; recovery file reloaded.

### Task 4: Engine server
**Files:** `server.py`, `__main__.py`, `tests/test_server.py`
**Produces:** HTTP API under a per-launch token: `POST /api/dictate`, `POST /api/notes/start|chunk|finish`, `GET /api/notes/live`, `GET/PATCH/DELETE /api/entries`, `POST /api/entries/{id}/reclean`, `GET/PUT /api/settings`, `/api/dictionary`, `GET /api/health`; static UI at `/`.
- [ ] Tests (TestClient, fake transcriber): dictate stores an entry; silent audio returns empty and stores nothing; search; reclean; settings never return keys' values.
- [ ] End-to-end test with Windows SAPI-synthesized speech through the real model.

### Task 5: Dashboard UI
**Files:** `ui/index.html`, `ui/app.css`, `ui/app.js`, bundled fonts.
- [ ] Views: History (timeline, search, filters), Notes, Dictionary, Settings, live note panel. Cream/ivory glass design. Playwright test loads it against a running engine and screenshots it.

### Task 6: Electron shell
**Files:** `package.json`, `app/main.js`, `preload.js`, `engine-process.js`, `hotkey.js`, `insert.js`, `capture.html`, `overlay.html`, tray + icon.
- [ ] Spawn/restart engine, tray menu, overlay pill, hold-to-talk (globalShortcut start + uiohook keyup stop), mic + loopback capture to 16 kHz PCM, paste with clipboard restore and failure toast, note toggle.
- [ ] Playwright-Electron test using Chromium's fake audio device with a synthesized WAV: simulate Ctrl+Space hold, assert text pasted into a focused test field and an entry in history.

### Task 7: Docs, repo, final verification
- [ ] README (install, privacy, hardware, limits), LICENSE, `.gitignore`, git init + commit. Run all tests, launch the app and open the dashboard for the user.
