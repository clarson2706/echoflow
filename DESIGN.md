# EchoFlow design

Theme: a bright reading room, daylight on cream paper. Light only.
Color strategy: Restrained. Tinted ivory neutrals; forest green for primary actions and selection; brass hairlines and the recording state only.
Tokens (OKLCH): ivory 0.975/0.012/85, cream 0.945/0.022/85, ink 0.26/0.03/160, muted 0.5/0.02/100, forest 0.38/0.07/160, brass 0.68/0.09/80.
Type: Cormorant Garamond for wordmark, view titles, note titles and empty states. Inter for all UI labels, data and body. Scale ratio 1.2.
Glass: translucent ivory (55%), blur 22px, 1px white specular border, inner top highlight, soft warm shadow. Used on rail, detail panel, live bar, overlay, popovers.
Motion: 180ms ease-out-quart on state change only.
